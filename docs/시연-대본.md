# HBM 시연 영상 대본 (ver 2 수정안)

- 길이: 약 3분 30초 (나레이션 기준)
- 구성: 문제 → 로그인 → 첫 화면 → 기획 한 건을 처음부터 끝까지 → 쌓인 기록 활용 → 마무리
- 표기: **[화면]** 은 영상에서 보여 줄 동작, **나레이션** 은 읽을 문장이자 자막입니다.

## 초안에서 바꾼 점

1. **순서를 "기획 한 건의 흐름"으로 묶었습니다.** 초안은 탭을 하나씩 소개하는 순서라 메일함·ERP가 끝에 따로 나왔습니다. 수정안은 날짜 → 투표 메일 → 장소 → 안내 메일 → 예약 → ERP 등록 → 자동 기록 순으로 한 번에 이어 보여 줍니다. ERP 연동이 "왜 필요한지"가 흐름 안에서 설명됩니다.
2. **사실과 다른 문장을 고쳤습니다.** 날짜 후보는 "부서원 설문 응답"이 아니라 부서원 캘린더와 과제 일정으로 계산합니다. 설문(투표)은 그다음 단계입니다.
3. **빠져 있던 기능을 넣었습니다.** 문제 제기와 HBM 이름의 뜻, 로그인과 소속 선택, 문장으로 기획 시작하기, 달력의 색 구분과 확정 확인 팝업, 투표 메일 발송 화면과 실시간 집계, 추천도 말풍선, 새로운 제안, 후기 폼 발송 질문, ERP 전표 자동 감지, 단체 사진 갤러리.
4. **이름이 바뀐 메뉴를 반영했습니다.** "부서원 프로필" 탭은 오른쪽 위 프로필 버튼 안의 "부서원 선호사항 설정"으로 옮겨졌습니다.

## 대본

### 1. 문제 제기 (약 20초)

**[화면]** 로그인 화면. 왼쪽의 HBM 로고와 쌓인 칩 일러스트.

**나레이션**
> 조직문화활동 기획은 보통 돌아가면서 맡습니다. 처음 맡으면 막막합니다. 우리 부서가 그동안 어디를 갔는지, 옆 부서는 무엇을 했는지 알 방법이 없기 때문입니다.
> 그래서 저희 팀은 조직문화활동 기획 에이전트, HBM을 만들었습니다. Happy Bonding Memory. 칩을 쌓아 붙이듯 유대감을 쌓고, 그 기억을 기록으로 남긴다는 뜻입니다.

### 2. 로그인 (약 10초)

**[화면]** 사번, 이름, 비밀번호를 직접 입력 → "다음" → 그룹 "R&D" → 팀 선택 → "HBM 시작하기".

**나레이션**
> 사번과 이름으로 로그인하고 소속 팀을 고르면, 그 팀의 기록과 부서원 일정을 기준으로 화면이 구성됩니다.

### 3. 첫 화면: 추천 (약 25초)

**[화면]** 첫 화면을 천천히 스크롤. 카드 줄을 좌우로 넘기고, 카드 하나에 마우스를 올림.

**나레이션**
> 첫 화면에는 추천이 바로 보입니다. 우리 부서가 최근 다녀온 곳, 다른 부서에서 평점이 좋았던 곳, 지금 계절에 자주 간 곳, 아직 덜 알려진 새로운 곳입니다.
> 카드 오른쪽 위의 색은 범주를, 아래 한 줄은 추천하는 이유를 알려 줍니다. 평점이 높은 곳에는 순위가 붙습니다.

### 4. 기획 시작과 조건 설정 (약 20초)

**[화면]** 입력창에 "다음 달에 3만원대로 회식하고 싶어"를 직접 타이핑 → "기획 시작". 조건 화면에서 유형과 기간이 채워진 것을 보여 주고, 예산 칸에 30000을 입력해 30,000으로 바뀌는 것을 보여 줌. 조직도에서 참석자 확인 → "에이전트에게 날짜 추천받기".

**나레이션**
> 기획은 문장 한 줄로 시작할 수 있습니다. 에이전트가 문장에서 유형과 예산, 기간을 읽어 조건을 채워 줍니다. 참석 대상은 사내 조직도에서 고릅니다.

### 5. 날짜 정하기 (약 35초)

**[화면]** 달력 화면. 초록 날짜가 빛나는 것을 보여 주고, 빨간 날짜를 눌러 오른쪽 패널의 사유를 보여 줌 → "이 날로 확정" → 확인 팝업 → "취소". 초록·노랑 날짜 몇 개를 골라 "고른 날짜로 투표 메일 보내기" → 메일 발송 단계 화면 → "데모: 부서원 3명 응답 받기"를 두 번 눌러 달력 색이 바뀌는 것을 보여 줌 → 표가 많은 날짜를 눌러 "이 날로 확정".

**나레이션**
> 에이전트는 부서원 캘린더와 과제 일정을 확인해 달력에 색으로 표시합니다. 모두 가능한 날은 초록, 일부가 어려운 날은 노랑, 불참이 많거나 중요한 과제 일정과 겹치는 날은 빨강입니다. 어려운 날을 고르면 한 번 더 확인합니다.
> 후보가 여럿이면 투표로 정합니다. 날짜를 고르고 버튼을 누르면 부서원에게 투표 메일이 발송되고, 응답이 들어오는 대로 달력에 실시간으로 반영됩니다.

### 6. 장소 정하기 (약 35초)

**[화면]** 장소 추천 화면. 맨 위 에이전트 조언과 날씨 줄 → 1순위 카드의 "추천도"에 마우스를 올려 말풍선 표시 → "추천 근거 보기"를 눌러 경비 기록과 후기 표시 → 아래 "새로운 제안"으로 스크롤 → 1순위 카드로 돌아와 "이곳으로 확정하고 안내 메일 보내기" → 메일 발송 화면.

**나레이션**
> 날짜가 정해지면 장소를 추천합니다. 근거는 이맘때 우리 부서와 다른 부서의 경비 기록, 참석자 후기, 사내 블로그의 단체 사진, 그날의 날씨, 그리고 부서원의 식이 제한과 선호입니다. 추천도에 마우스를 올리면 이유를 볼 수 있습니다.
> 늘 가던 곳이 아닌 새로운 곳도 따로 제안합니다. 장소를 확정하면 참석자 전원에게 안내 메일이 발송됩니다.

### 7. 예약부터 기록까지 (약 40초)

**[화면]** 확정 화면. 후기 폼 질문에 "네, 작성해서 발송" → "예약하기"를 눌러 네이버 지도가 열리는 것을 잠깐 보여 줌 → "활동 후 ERP에 경비 등록"을 눌러 ERP 화면(내용이 미리 채워져 있음)에서 등록 → HBM으로 돌아오면 단계가 "기록"으로 바뀜 → 메일함에서 "기록 업데이트" 메일 열기 → "기록 보고 코멘트 남기기" → 코멘트를 직접 타이핑해 추가.

**나레이션**
> 확정 화면에서는 후기 폼을 보낼지 묻고, 예약 페이지를 바로 열어 줍니다.
> 활동이 끝나고 담당자가 ERP에 법인카드 내역을 올리면, 에이전트가 ERP 화면을 읽어 부서 기록으로 자동 등록합니다. 담당자에게는 알림 메일이, 참석자에게는 후기 폼이 갑니다. 담당자는 다음 사람을 위한 코멘트만 남기면 됩니다.

### 8. 쌓인 기록 활용 (약 25초)

**[화면]** "우리 부서 기록" 탭: 타임라인과 오른쪽 "많이 간 곳" → "타부서 레퍼런스" 탭: 유형과 계절로 걸러 보기 → 장소 하나를 눌러 부서별 방문 횟수, 단체 사진 → 갤러리 화면 → 오른쪽 위 프로필 버튼 → "부서원 선호사항 설정"에서 알레르기 칸에 직접 입력.

**나레이션**
> 이렇게 쌓인 기록은 다음 기획의 출발점이 됩니다. 우리 부서 기록에서는 입사 전 활동까지 볼 수 있고, 타부서 레퍼런스에서는 다른 부서가 언제 어디서 얼마를 썼는지, 반응이 어땠는지 확인할 수 있습니다.
> 부서원의 식이 제한과 알레르기, 선호는 한 화면에서 관리하고, 다음 추천에 바로 반영됩니다.

### 9. 마무리 (약 10초)

**[화면]** 오른쪽 위 "에이전트 로그"를 열어 에이전트가 한 일 목록을 보여 준 뒤, 첫 화면으로 돌아감.

**나레이션**
> 날짜 잡기부터 장소 추천, 안내, 경비 기록, 후기까지. HBM은 처음 맡은 담당자도 한 번의 흐름으로 조직문화활동을 준비할 수 있게 돕습니다. 감사합니다.

## 촬영 메모

- 시연 계정: 사번 20260001, 이름 박시진, 그룹 R&D, 팀 공정개발2팀
- 촬영 전에 데모 데이터를 초기화해 메일함과 기획 목록을 비워 둡니다.
- ERP 등록 후 자동 감지까지 로컬은 최대 10초, 배포 사이트는 몇 초가 걸립니다. 영상에서는 이 구간을 잘라 붙입니다.
- 네이버 지도는 외부 사이트라 2~3초만 보여 주고 넘어갑니다.
